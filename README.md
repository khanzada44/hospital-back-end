-Project Title
# Hospital Backend API

-Short Description
A Node.js + Express + PostgreSQL based backend system for hospital management with authentication, role-based access control, and error handling middleware.

-Tech Stack
- Node.js
- Express.js
- PostgreSQL
- JWT Authentication
- dotenv

## Features
- User authentication (Login/Register)
- Role-based access control (Admin/User)
- Soft delete (archive users)
- Error handling middleware
- PostgreSQL integration
- Secure API structure

## Installation

1. Clone repo
git clone <repo-url>

2. Install dependencies
npm install

3. Create .env file

4. Run project
npm run dev


## Notes
- .env file is required to run project
- node_modules is not included in repo
- Database must be PostgreSQL
